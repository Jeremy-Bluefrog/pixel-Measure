# Implementation Plan - Material 3 Expressive UI Upgrade

This plan outlines the complete modernization of the application's user interface to fully adopt **Material 3 Expressive** design guidelines.

---

## Proposed Changes

### 1. Theme & Shapes (`Theme.kt`)
- Update shape definitions and dynamic color mappings to feature high-contrast, expressive container tones.

### 2. Navigation & Top Bar (`ModernArTopBar.kt`)
- Redesign top action chips into floating expressive capsules with soft glowing borders.

### 3. Bottom Control Deck (`ModernArBottomDeck.kt`)
- Upgrade shutter button and measurement action buttons with expressive press-scale animations and vibrant gradient glows.
