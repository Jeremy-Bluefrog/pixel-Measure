# 應用程式潛在錯誤審查與強固化計畫

本計畫針對使用者指定的重點項目（相機 AR 測量與感測器融合、裝置相容性與權限處理、潛在執行階段異常與邊界條件、多語系翻譯與 UI 跑版檢查）進行全面性錯誤審查與強固。

## 用戶審查與關鍵決策

> [!IMPORTANT]
> 我們將針對 AR 相機初始化、感測器防抖動異常、權限拒絕狀態處理、極端螢幕解析度跑版進行全面防護。

- **確認審查範圍**: 相機 AR 測量、感測器融合計算、權限導引、多語系字串完整性與 UI 響應式佈局。
- **預設安全策略**: 對所有外部感測器與相機 HAL 互動加入防呆與漸進降級 (Graceful Degradation)。

---

## 1. 概覽與核心目標

- **目標**: 徹底排查並修復相機、感測器、權限及 UI 介面在不同裝置與極端操作下可能出現的潛在錯誤與例外。
- **涵蓋範圍**:
  1. `HighSpeedCamera2Manager` 與 `ModernArCameraView` 之生命週期與相機開啟失敗防護。
  2. `MeasureViewModel` 與 `ArMath` 中矩陣運算與邊界條件 (除以零、無效浮點數檢查)。
  3. 權限拒絕後的使用者體驗與系統設定跳轉。
  4. 多語系翻譯完整性與小螢幕 / 大螢幕跑版檢查。

---

## 2. 使用者體驗與視覺設計

- **錯誤防護 UI**:
  - 當相機或感測器異常時提供友善的錯誤提示與一鍵重試 / 前往設定按鈕。
  - 確保在各種長寬比螢幕下，按鈕與導航欄不會被遮擋或發生文字溢出 (Text Overflow)。
- **無縫降級體驗**:
  - 在不支援 ARCore 或高幀率的裝置上無縫切換至 3D 空間感測器融合與 Camera2 直通模式，保持測量功能正常運作。

---

## 3. 關鍵架構與防錯策略

```
┌─────────────────────────────────────────────────────────────┐
│                 ModernArCameraView                          │
│  (Permission State & Lifecycle Observer & Surface Sync)     │
└──────────────┬──────────────────────────────┬───────────────┘
               │                              │
               ▼                              ▼
┌──────────────────────────────┐  ┌───────────────────────────┐
│   HighSpeedCamera2Manager    │  │       MeasureViewModel    │
│  (Safe FPS & AF Negotiation) │  │  (Sensor Fusion & Matrix) │
└──────────────┬───────────────┘  └─────────────┬─────────────┘
               │                                │
               └──────────────┬─────────────────┘
                              ▼
               ┌──────────────────────────────┐
               │         ArMath.kt            │
               │  (Safe Matrix & Projection)  │
               └──────────────────────────────┘
```

- **相機與權限防護**:
  - 嚴格檢查 `ContextCompat.checkSelfPermission`，對未授權狀態提供直覺的引導與設定跳轉。
  - 為 `CameraDevice.StateCallback` 與 `CameraCaptureSession.StateCallback` 增加完整錯誤捕獲與自動重試機制。
- **數學運算防呆 (`ArMath.kt` / `VulkanMatrix4.kt`)**:
  - 防止矩陣投影計算中的 `NaN`、無窮大及零除數錯誤。
- **多語系與 UI 檢核**:
  - 確保所有介面字串皆透過 `TranslationManager` 或 `strings.xml` 讀取，防止硬編碼文字或未翻譯鍵值導致空白。

---

## 4. 驗證計畫

- 執行 `gradle :app:compileDebugKotlin` 確保所有程式碼編譯完全通過。
- 透過靜態檢查確認無未處理的例外、未捕獲的協同程式異常及 UI 跑版隱患。
